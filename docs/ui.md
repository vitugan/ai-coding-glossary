# UI сайту

Узгоджені рішення щодо інтерфейсу. Основа — Astro Starlight; компоненти Starlight не перевизначаємо без потреби.

## Мови й навігація

- `defaultLocale: en` (Основна мова). Сторінка без Перекладу показує EN-текст зі стандартним повідомленням Starlight.
- Сайдбар генерується з `content/structure.yaml` + `content/<lang>/language.yaml`: розділи пронумеровані («1. Модель»), згорнуті, крім розділу поточного терміна.
- В UK-сайдбарі внизу окремий пункт «Глосарій перекладу» (`/uk/equivalents/`).

## Головна мови (`/<lang>/`)

Splash-сторінка: hero (назва, підзаголовок, кнопки «Почати з першого терміна» і «Пошук»), вступ з `content/<lang>/intro.md`, далі картки розділів зі списками термінів.

## Сторінка терміна

1. Назва (`title`).
2. На сторінках не EN: підзаголовок «EN: <назва EN-терміна> · також: <aliases>» — для пошуку обома мовами.
3. `description` як лід.
4. Основний текст.
5. `## avoid` → aside типу caution з підписом мовою сайту («Уникайте» / «Avoid»).
6. `## usage` → заголовок «Приклад» / «Usage», абзаци — репліки діалогу, по черзі ліворуч і праворуч.
7. Права колонка «На цій сторінці» вимкнена.
8. Внизу: «Редагувати цю сторінку» (або «Перекласти цей термін», якщо Перекладу немає — створює файл із EN-текстом як заготовкою), «Повідомити про помилку» (Issue з назвою терміна). Дату оновлення не показуємо.
9. Пагінація «попередній / наступний» у порядку `structure.yaml`.

## Вигляд

- Стандартний Starlight + легка айдентика: власний колір акценту (світла/темна тема), текстовий логотип, шрифт Inter.
- Колір і логотип обираються з 2–3 варіантів на живому сайті.
- У шапці: пошук (Pagefind), перемикач мов, перемикач теми, іконка GitHub.
- Футер: загальна атрибуція Upstream.
