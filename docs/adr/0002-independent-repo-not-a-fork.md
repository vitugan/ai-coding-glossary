# Окремий репозиторій без технічного зв'язку з Upstream

Словник живе в новому публічному репо з чистою історією, а не у форку `mattpocock/dictionary-of-ai-coding`: немає upstream-remote, submodule, автоматичної синхронізації чи позначок походження в термінах. Зміни в Upstream переглядаються вручну і переносяться вибірково. Причини: наш EN-текст Запозичених термінів може як завгодно відрізнятися від Upstream, тож автоматичне злиття давало б лише конфлікти; Словник містить Власні терміни й власну структуру; в Upstream немає ліцензії, і переносити його історію в наш публічний репо — ризик без користі.

## Considered Options

- **Форк із перекладом поверх оригіналу** (стартовий стан) — відкинуто: кожна правка Upstream давала конфлікт із повністю переписаним файлом.
- **Відстеження версії Upstream для кожного терміна** з diff між Переглядами — відкинуто: зайва складність для рідкісної ручної роботи.

## Consequences

Атрибуція Upstream — лише загальна, у футері сайту та README. Під час Перегляду Upstream відповідність між файлами Метта і нашими термінами відновлюється вручну (зазвичай за назвою).
