Один обмін «туди й назад» між [оснащенням](./harness.md) до [провайдера моделі](./model-provider.md). Оснащення надсилає поточний [контекст](./context.md); провайдер повертає одну відповідь ([виклик інструменту](./tool-call.md) або остаточну відповідь). Одне повідомлення користувача може викликати багато обмінів, якщо [агент](./agent.md) викликає [інструменти](./tool.md) — кожен [результат виконання інструменту](./tool-result.md) викликає ще один обмін.

Кожен запит несе все: [системний промпт](./system-prompt.md), повну історію розмови, кожен результат виконання інструменту. Модель [без стану](./stateless.md), тому провайдер нічого не зберігає між запитами — сороковий запит надсилає те, що надіслав тридцять дев'ятий, плюс ще один результат виконання інструменту. [Кеш префіксів](./prefix-cache.md) існує, щоб зробити це повторення доступним за ціною.

Запит також є одиницею білінгу. [Вхідні токени](./input-tokens.md), [вихідні токени](./output-tokens.md) та знижки за кешування — все рахується за запит, тому питання може коштувати несподівано дорого: вартість пропорційна не вашому повідомленню, а кількості запитів помноженій на розмір контексту, який несе кожен з них.

Важливо тримати запит окремо від [кроку](./turn.md). Крок — це один обмін з вами, а один крок — "виправ тест, що падає" — відіграється як низка запитів:

| Запит | Відповідь моделі      | Оснащення потім                   |
| ----- | --------------------- | --------------------------------- |
| 1     | Tool call: run tests  | Запускає їх, додає результат      |
| 2     | Tool call: read file  | Додає вміст файлу                 |
| 3     | Tool call: read file  | Додає вміст файлу                 |
| 4     | Tool call: edit file  | Застосовує зміни, додає результат |
| 5     | Tool call: run tests  | Запускає їх, додає результат      |
| 6     | Final answer: "fixed" | Показує вам                       |

Шість запитів на один крок — кожен запит повторює весь контекст. Коли ви дивуєтеся, куди поділися [токени](./token.md), рахуйте запити, а не кроки.

## usage

"Одне питання спалило сорок тисяч токенів?"

"Дивись на виклики інструментів — дванадцять grep, вісім read, чотири edits. Кожен результат інструменту породжує новий запит, і весь префікс [сесії](./session.md) надсилається кожен раз."
