# EN — Основна мова Словника

Попри те, що проєкт український, кожен термін Словника обов'язково існує англійською (CI блокує PR без EN-версії), а всі інші Мови, включно з UK, є Перекладами з EN. Причини: більшість термінів запозичена з англомовного Upstream; перекладачі майбутніх Мов (польська тощо) напевно читають EN, але не UK; сайт завжди має текст для показу, коли Перекладу немає.

## Considered Options

- **UK як Основна мова** — відкинуто: для Запозичених термінів це була б фікція, а нові Мови довелося б перекладати з української.
- **Без Основної мови**, з ланцюжками fallback для кожної Мови — відкинуто: стає неможливо визначити, з чого робити Переклад, і може не знайтися жодного тексту для показу.

## Consequences

Власний термін не можна опублікувати лише українською: автор додає й EN-версію в тому ж PR.
